개인정보처리방침

시행일: 2026년 11월 25일

디씽크스튜디오(이하 「회사」)는 내부 업무용 애플리케이션 「dethink-claude」(이하 「앱」)를 운영하며, 앱이 Google 계정 정보에 접근하고 처리하는 방식을 아래와 같이 알립니다.

1. 앱의 목적과 이용자

앱은 회사 대표가 자신의 업무를 처리하기 위해 쓰는 내부용 도구입니다. 회사 외부의 일반 이용자에게 제공하지 않습니다.

2. 접근하는 정보

이용자가 Google 로그인으로 허용한 범위 안에서만 다음 정보에 접근합니다.

  • Gmail: 메일 검색·조회, 초안 작성
  • Google Calendar: 일정 조회·등록·수정
  • Google Drive: 파일 조회·생성·수정

3. 이용 목적

접근한 정보는 이용자가 직접 지시한 업무(일정 관리, 메일 확인, 문서 저장)를 처리하는 데만 씁니다. 광고, 판매, 프로파일링에는 쓰지 않습니다.

4. 보관과 제3자 제공

  • Google 정보는 이용자의 PC에서 처리합니다. 회사는 이를 별도 서버에 모아 보관하지 않습니다.
  • 업무 처리를 위해 AI 모델 제공자(Anthropic)에게 해당 요청 내용이 전송될 수 있습니다.
  • 그 밖의 제3자에게 판매하거나 제공하지 않습니다.

5. Google API 서비스 사용자 데이터 정책 준수

앱이 Google API에서 받은 정보를 사용하고 다른 앱으로 전송하는 것은 Limited Use 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

6. 접근 철회와 삭제

이용자는 언제든지 Google 계정 → 타사 앱 및 서비스에서 앱의 접근 권한을 철회할 수 있습니다. 철회하면 앱은 더 이상 Google 정보에 접근하지 못합니다.
